# Format: topics, tags and generated pages

A **topic** is a folder name under `library/`, `notes/` and `writing/`. One tag is one topic;
`econ/labor` nests. `vault.py tidy` reads it from, in order: frontmatter `tags:` or `topic:`, the
first inline `#tag` (code, URLs, headings and digit-only tags do not count), a `#tag` or leading
`[tag]` in the file name (`.` nests, since a name cannot hold `/`), a tagged note that links the
file, or a topic given in chat. The first tag picks the folder; all tags stay on the page.

Pages carry `topic:` (and `tags:`) so Obsidian's tag pane and graph groups can filter by it.
Concepts may carry `domain:` instead; it is read as the topic.

**Topic page** `wiki/topics/<topic>.md` is generated by `vault.py index` and never edited:
subtopics, sources (with gists), concepts (with status), your notes, writing, and library
folders with no source page yet ("Waiting to learn"). The Topics block in `VAULT.md` between
`<!-- topics -->` and `<!-- /topics -->` is generated the same way; the rest of the file is yours.

**`_meta/index.json`** holds one node per page (type, title, aliases, gist, status, box,
topic, tags, links, "Seen in" and "Connects to"), re-parsed only when a file's mtime or size
changes. Query it with `about`, `where` and `changed`; do not read it directly.
